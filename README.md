```
$ socli
socli is a command line tool for managing SeriousOJ.

Usage: socli [command] [options]

Commands:

  announcement   manage announcements (create)
  contest        manage contests (list)
  judge          manage judges (list)
  login          login to SeriousOJ
  user           manage users (get, create, update, password)
  version        show version
```
